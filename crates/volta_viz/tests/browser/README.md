# Real browser regression

This optional check opens a generated v1 run store in Chromium. It exercises every recorded run, source/event selection, four applicable native checks, wave64 grouping, lane/search/status filters, unsupported source highlighting, theme/help, and recovery after a lane filter matches no lanes. It writes screenshots and a JSON receipt, and fails on browser exceptions or console errors.

Install the pinned browser dependency from this directory:

```sh
npm install
npx playwright install chromium
```

The test expects a **mixed validation store** containing PTX runs, native gfx942 successes and typed failures, gfx950 runs, and a typed unsupported HipKittens softmax run named `hipkittens-softmax`. The run recorder accepts existing source and launch JSON pairs and does real analysis/checking; an unsupported source is recorded without inventing a graph or successful proof:

```sh
cargo run -p volta_pipeline --example record_viewer_runs -- \
  /tmp/volta-mixed-viz \
  ptx-success ptx /path/to/kernel.ptx /path/to/ptx.launch.json \
  hipkittens-softmax amdgpu /path/to/softmax.s /path/to/softmax.wg0.launch.json
```

Run the gfx942 compiler tests with `VOLTA_VIZ_DIR=/tmp/volta-mixed-viz` to add real compiler successes and barrier/wait/NOP mutations. After appending runs, invoke the recorder again to rebuild `index.html` with the current viewer. The recorder includes every existing run in that store. HipKittens assembly is generated by the documented extraction workflow in `external/hipkittens`; it is not a checked-in fixture.

From the repository root:

```sh
node crates/volta_viz/tests/browser/viewer.spec.cjs \
  /tmp/volta-mixed-viz/index.html /tmp/volta-browser-evidence
```

`PLAYWRIGHT_MODULE` can point to an externally installed Playwright module, avoiding a repository-local `node_modules`. These browser assertions validate rendering and interaction. They do not add mathematical or hardware validation to a recorded result.
